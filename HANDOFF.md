# ERC-8415 Kit Handoff

## Purpose

This repository contains the ERC-8415 Native Infrastructure Kit implementation task.

## Semantic Requirements

The implementation must preserve:

- holderAsOf(t)
- entryAsOf(t)
- isFinalAsOf(t)
- provisional and final semantics
- append-only temporal projection
- proof-profile admission
- cancellation is not finality
- gap closure is not finality

## Execution

Use repository-local documents as the source of truth.

Complete semantic kernel first, then proof profiles, settlement extension, API, SDK and conformance delivery.
